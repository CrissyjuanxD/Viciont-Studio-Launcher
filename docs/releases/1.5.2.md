## Packs nuevos sin salir del servidor (plugin y mod ViciontRP)

- Cuando publicas una versión con los resource packs cambiados, quien está jugando en tu servidor desde el launcher los recibe **sin salir del juego**: sale abajo **«Descargando Assets»** con una barra blanca y, al llenarse, se recargan las texturas.
- El launcher cambia **la carpeta `resourcepacks` de la instancia**, solo los packs que cambiaron. No se duplica nada y funciona también con los resource packs ocultos.
- Si en esa versión solo cambiaron packs, ya no sale el botón **Actualizar** en la instancia. Si también cambiaron mods o configs, esos se actualizan como siempre con el botón.
- El launcher añade automáticamente el **mod ViciontRP** a las instancias Fabric o Quilt que usan el plugin (por ahora Minecraft 1.21, 1.21.1, 1.21.11 y 26.2). En otras versiones, el apartado del pack del servidor avisa de que la actualización dentro del juego no es compatible.
- El plugin puede pedir que solo se entre **con el launcher**: el launcher le da al mod un pase de cada partida para demostrarlo.

## Varios packs del servidor

- En **Contenido → Pack del servidor de Minecraft** ya se pueden marcar **varios packs** (hasta 8) para quien entra sin el launcher.
- Necesita el servidor actualizado (API 16).

## Descargar

En **Assets**: **.exe** para Windows, **.dmg** para macOS y **.AppImage**, **.deb** o **.rpm** para Linux. Se mantienen los enlaces fijos y el sistema de actualizaciones habitual.
