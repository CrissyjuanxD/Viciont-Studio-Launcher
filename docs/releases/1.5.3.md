## Contador de packs dentro del juego

- Mientras el mod ViciontRP actualiza los packs sin salir del servidor, el launcher le dice cuántos archivos lleva descargados. El mod lo muestra así: **«Actualizando Assets 100% | (0/3)»** (necesita ViciontRP 1.1.1).

## Descargar

En **Assets**: **.exe** para Windows, **.dmg** para macOS y **.AppImage**, **.deb** o **.rpm** para Linux. Se mantienen los enlaces fijos y el sistema de actualizaciones habitual.
