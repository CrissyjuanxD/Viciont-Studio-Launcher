## Pack del servidor de Minecraft (plugin ViciontRP)

- En **Administrar instancias → Contenido → Pack del servidor de Minecraft** eliges qué resource pack de la instancia usa tu servidor de Minecraft. Puede ser un `.zip` o una carpeta: si es una carpeta, el launcher crea su `.zip` al publicar.
- Con el plugin [ViciontRP](https://github.com/CrissyjuanxD/ViciontRP/releases/latest) en tu servidor, quien entra **sin el launcher** recibe ese pack. A quien juega **desde el launcher con la instancia al día** no se le pregunta nada.
- Si cambias algo del pack y publicas una versión nueva, el plugin recibe el pack nuevo solo. Si el pack no cambió, no se vuelve a crear ni a subir.
- Desde el mismo apartado creas la **clave del plugin** que se pone en su `config.yml`.
- Necesita el servidor actualizado (API 15).

## Descargar

En **Assets**: **.exe** para Windows, **.dmg** para macOS y **.AppImage**, **.deb** o **.rpm** para Linux. Se mantienen los enlaces fijos y el sistema de actualizaciones habitual.
