## Actualizaciones del launcher más seguras (Windows)

- El launcher ya **no se cierra** si Windows no deja abrir el instalador de la actualización (por ejemplo, por el antivirus o Smart App Control). En su lugar avisa de lo que pasó y deja **Reintentar** o **Ir a la descarga** para instalarla desde la web encima, conservando instancias y cuentas.
- Solo se piden permisos de administrador cuando de verdad hacen falta. Si Windows los pide, la pantalla de actualización lo dice («pulsa **Sí**») y, si no se aceptan, el launcher sigue abierto y lo avisa.
- Si una actualización no se termina de instalar, al volver a abrir el launcher sale un aviso con el enlace a la descarga.
- Cada fallo al instalar una actualización llega al panel con el motivo.

## Descargar

En **Assets**: **.exe** para Windows, **.dmg** para macOS y **.AppImage**, **.deb** o **.rpm** para Linux. Se mantienen los enlaces fijos y el sistema de actualizaciones habitual.
